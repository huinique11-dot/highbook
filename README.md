# 인천 고입 길잡이

인천 중학교 3학년 학생과 학부모를 위한 고입 정보 웹앱입니다. 빌드나 서버 없이 정적 파일만으로 동작합니다.

## 기능
- **학교·학과**: 2027 고입 파노라마에 실린 특성화고·마이스터고 28개교의 학과, 모집 인원, 특별전형 선발 방법, 자격증, 진로를 보여 줍니다. 학교마다 2022~2025 커트라인과 합격·불합격 사례가 함께 나옵니다. 계열별(기계, 디자인, 보건 등) 학과 모음도 있습니다.
- **합격권 찾기**: 석차백분율, 성별, 전형, 기준 연도를 넣으면 지원 가능한 학과를 안정권, 적정권, 소신권, 도전권으로 나눠 보여 줍니다.
- **파노라마 전체보기**: 2027 고입 파노라마 20쪽 전체를 원문 이미지와 글자로 볼 수 있습니다.
- **전체 검색**: 학교, 학과, 커트라인 사례, 파노라마 전 쪽을 한 번에 검색합니다. 비슷한 표현(예: 미술중점 → 예술중점)도 찾습니다.
- **책갈피**: 학교, 학과, 커트라인, 파노라마 쪽, 검색어를 저장하고 메모를 남깁니다. 기기(브라우저)에만 저장됩니다.
- **일정·출결**: 2027학년도 입학전형 일정(D-day 표시), 출석 점수 계산기, 300점 성적 산출표, 참고 사이트 목록.

## 파일 구성
- `index.html`, `assets/app.js`: 화면과 로직
- `data/cutoffs.js`: 커트라인 (scripts/build_data.py 로 생성)
- `data/panorama.js`: 파노라마 쪽별 글자, 학교·학과 정보, 계열 분류 (scripts/build_panorama.py 로 생성)
- `data/panorama/p07~p12.json`: 이미지로만 된 7~12쪽을 옮겨 적은 자료
- `assets/panorama/p-01~20.jpg`: 파노라마 원문 이미지

## 데이터 갱신
```bash
python3 scripts/build_data.py 커트라인.xlsx
python3 scripts/build_panorama.py
```

## 개인정보
앱과 데이터에는 이름·연락처 등 개인을 알아볼 수 있는 정보를 넣지 않습니다. 자료는 암호화되어 공개 저장소에 올라가며, 관리자 키가 있어야 열람할 수 있습니다.

> 이 앱의 모든 정보는 참고자료일 뿐이며, 이를 바탕으로 한 진학 결정과 그 결과에 대한 책임은 본인에게 있습니다.
